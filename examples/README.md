# CSV QA examples

Sample VIN inputs only, not verified recall results. mixed-vins.csv and headerless-vins.csv should preview 4 rows, 2 valid unique VINs, 1 duplicate and 1 invalid row, costing at most 2 credits. review-preview.csv should preview 3 rows, 1 valid unique VIN, 1 duplicate and 1 invalid row, costing at most 1 credit. Previewing is free; asking to check the file authorizes that one batch. Provider failures remain unresolved and are not charged.
