# RecallsNearMe

RELEASE CANDIDATE. The production MCP endpoint and per-host OAuth registrations must be accepted before public installation.

Connect your existing account using OAuth. Ask to show your balance, preview a VIN check, or read verified changes. Asking to check a VIN or CSV starts that one batch using existing credits, without a second confirmation. Recurring monitoring and audit spending changes need separate approval. One credit is charged only for a verified settled check. Provider failures remain unresolved. Credits and digital subscriptions are managed on the RecallsNearMe website. No payment is initiated by connecting.

For local validation: claude plugin validate . --strict. Load the folder with --plugin-dir, or install it through your operator-provided marketplace.
