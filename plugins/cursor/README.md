# RecallsNearMe

RELEASE CANDIDATE. The production MCP endpoint and per-host OAuth registrations must be accepted before public installation.

Connect your existing account using OAuth. Ask to show your balance, preview a VIN check, or read verified changes. Starting checks and recurring monitoring requires explicit approval. One credit is charged only for a verified settled check. Provider failures remain unresolved. Credits and digital subscriptions are managed on the RecallsNearMe website. No payment is initiated by connecting.

Install through a Git repository containing a .cursor-plugin/marketplace.json wrapper that references this package. Import that repository from Cursor Customize; a plain folder import is insufficient. This native Cursor package includes its static public OAuth client configuration.
